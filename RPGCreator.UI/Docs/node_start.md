### Start node

This node is the base of everything, its from here that the blueprint will start.

For example, if you link a [Print Node](goto:rpgc://docs/print_node) to this node, the print node will be called at the start of the blueprint.

*Do not forgot to link the [End Node](goto:rpgc://docs/end_node) at the end of your blueprint, or else it will **refuse** to work!*
